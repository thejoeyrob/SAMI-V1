# Start here

This is the clean SAMI v1.0.0 repository baseline.

1. Create a new GitHub repository.
2. Upload these repository contents, preserving `.github/workflows/pages.yml`.
3. In GitHub Settings → Pages, select **GitHub Actions** as the source if it is not selected automatically.
4. Future development should branch from `main`; keep `main` as the accepted release line.

The separate ROOT-FLAT PWA ZIP contains only deployable runtime files and no repository folders.
